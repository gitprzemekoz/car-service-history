# Słownik domeny — car-service-history

Krótki słownik dla agentów. Szczegóły i dowody: `context/domain/01-domain-distillation.md`.

| Termin                              | Co znaczy                                                                                               | Nazwa w kodzie                                         | Jak tego NIE nazywać                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------- |
| Klient (rekord)                     | Kartoteka klienta zakładana przez mechanika. Może jeszcze nie mieć konta.                               | `clients`, `Client`                                    | „user”, „account”, „customer”                                       |
| Klient (rola)                       | Zalogowany właściciel pojazdu. Tylko czyta swoją historię.                                              | `role = 'client'`, `Role`                              | „owner account”, „viewer”                                           |
| Powiązany / oczekuje na rejestrację | Rekord klienta z ustawionym `user_id` albo bez niego. Wiąże go wyłącznie trigger rejestracji po emailu. | `clients.user_id`, „Linked” / „Waiting for signup”     | „connected”, „invited”, „active”                                    |
| Mechanik                            | Konto z rolą zapisującą: zakłada klientów, dodaje i edytuje wpisy                                       | `role = 'mechanic'`, `mechanic_id`                     | „admin”, „technician”, „service”                                    |
| Warsztat                            | Granica widoczności klientów. W MVP 1 mechanik = 1 warsztat; osobnego bytu nie ma.                      | `clients.mechanic_id`                                  | „service” (to słowo zarezerwowane dla usług), „shop”, `workshop_id` |
| Pojazd                              | Auto klienta. Klient ma dokładnie jeden.                                                                | `vehicles`, `Vehicle`                                  | „car” w kodzie, „asset”                                             |
| Numer rejestracyjny                 | Tablica rejestracyjna, zapisywana wielkimi literami                                                     | `registration_number`                                  | „plate”, „VIN”, „reg”                                               |
| Wpis serwisowy                      | Jedna wykonana usługa dla pojazdu                                                                       | `service_entries`, `ServiceEntry`                      | „record”, „job”, „visit”, „order”                                   |
| Typ usługi                          | Co zostało zrobione (tekst)                                                                             | `service_type`                                         | „category”, „kind”                                                  |
| Data serwisu                        | Dzień wykonania usługi (bez godziny, nie w przyszłości)                                                 | `service_date`                                         | „created_at” (to data zapisu)                                       |
| Przebieg                            | Stan licznika w chwili serwisu                                                                          | `mileage`                                              | „odometer”, „km” w nazwach pól                                      |
| Koszt                               | Cena usługi; nigdy nie trafia do widoku udostępnionego                                                  | `cost`                                                 | „price”, „amount”                                                   |
| Interwał następnego serwisu         | Przebieg i/lub data następnego serwisu zadeklarowane przy wpisie (co najmniej jedno)                    | `next_due_mileage`, `next_due_date`                    | „due”, „deadline”, „reminder date”                                  |
| Następny serwis                     | Punkt next-due z **najnowszego** wpisu; starsze wpisy się nie liczą                                     | `nextService()`, `NextService`                         | „upcoming service” liczony z wielu wpisów                           |
| Historia serwisowa                  | Pełna lista wpisów pojazdu od najnowszego, z kosztem; dla klienta i jego mechanika                      | `ServiceHistory`, `sortNewestFirst()`                  | „log”, „timeline”                                                   |
| Edycja                              | Korekta wpisu przez jego autora. Zawsze zostawia rewizję i znacznik „Edited”.                           | `updated_at`, „Edited”                                 | „update” w UI, „overwrite”                                          |
| Rewizja                             | Niezmienna kopia poprzednich wartości wpisu po edycji; niewidoczna dla ról                              | `service_entry_revisions`                              | „version”, „history” (to inne pojęcie), „audit log”                 |
| Link udostępniający                 | Publiczny token ważny 24h, najwyżej jeden na pojazd; można go odwołać lub zastąpić                      | `share_links`, `ShareLink`, `create_share_link()`      | „invite”, „public URL”, „Linked”                                    |
| Historia udostępniona               | Zredagowany widok dla posiadacza linku: typ, data, przebieg i pojazd; bez kosztu, notatek i next-due    | `get_shared_vehicle_history()`, `SharedVehicleHistory` | „service history” (to pełna wersja), „public profile”               |
| Odwołanie linku                     | Usunięcie aktywnego linku przez klienta                                                                 | `revoke_share_link()`                                  | „delete link”, „expire”                                             |
| Wygaśnięcie                         | Link przestaje działać 24h po utworzeniu; wygląda wtedy tak samo jak link nieistniejący                 | `expires_at`, `isActive()`                             | „timeout”, „TTL” w UI                                               |
| Kupujący                            | Anonimowy odbiorca linku                                                                                | `anon` (rola bazy)                                     | „guest user”, „client”                                              |
| Profil / rola                       | Rola konta nadawana raz przy rejestracji; użytkownik jej nie zmienia                                    | `profiles`, `Role`                                     | „permissions”, „user type”                                          |
| Zgłoszenie błędnego wpisu           | (planowane, FR-007) Klient oznacza wpis jako błędny, a autor to widzi                                   | — (brak)                                               | „complaint”, „dispute”, „ticket”                                    |
| Przypomnienie                       | (planowane, FR-008) Email do klienta, gdy zbliża się następny serwis                                    | — (brak)                                               | „notification” ogólnie, „alert”                                     |
